# 配乐：代码合成的踩拍 EDM

music.py 用振荡器和噪声合成一首 128 BPM、A 小调（Am–F–C–G）的曲子，不用任何采样或第三方音频。配器根据 `MUSIC_SECTIONS` 的模式自动编排，重音根据 `CUES` 自动放置。所以只要改画面时间轴，配乐会跟着对齐。

## 段落模式

| 模式 | 鼓 | 低音 | 和弦 | 其他 |
|---|---|---|---|---|
| `pad` | 无 | 无 | 超锯齿铺底，截止频率 650 Hz，渐入 | 终端开场 |
| `pulse` | 每拍底鼓（心跳） | 无 | 900 Hz | 段内照片每张一记轻击 |
| `build` | 底鼓 + 16 分闭镲渐强，后半段加开镲 | 8 分音符，滤波逐渐打开 | 600 → 5000 Hz 打开 | 进入下一段前有军鼓滚奏和上扬噪声 |
| `full` | 四拍底鼓、反拍拍手、开闭镲 | 16 分音符 + 每拍 sub | 6500 Hz，全开 | 16 分琶音；段首有镲，长段每 16 拍再一下 |
| `break` | 无 | 无 | 1200 Hz | 半速拨弦，情绪段 |
| `count` | 每拍底鼓 | 无 | 无 | 每个 slam 一记和弦重击，走一遍和弦进行 |
| `reveal` | 无 | 无 | 无 | 全曲最大的一击，主和弦长音 |
| `hit` | 无 | 无 | 3200 Hz | 只有画面 cue 的重击 |
| `mid` | 中等律动 | 8 分音符 | 3200 Hz | 讲师卡片 |
| `end` | 无 | 无 | 无 | 最后一击，和弦余音拖到片尾，最后 2 s 淡出 |

## 每段可选覆盖（第 4 个元素 dict）
- `roll`：进入本段前军鼓滚奏的拍数。默认前一段是 build 时为 8，否则为 4；填 0 表示不要。
- `breath`：本段开始前 1/4 拍音乐压低到的增益，制造一口「换气」后再砸下去。默认 full 0.15、break 0.3、count 0.15、reveal 0.1、end 0.1；填 0 表示不要。
- `fill`：full 段结尾接 full 或 break 时，最后两拍要不要军鼓加花（默认 True）。

## 跟着画面自动加的音效
- **slam**：重击 + 前置气流声。倒数段及之后的 slam 更重。
- **照片跟踪框锁定**：一声提示音。
- **keynote 卡片**：落地时一记轻击，锁定时一声提示音。
- **trackwall**：标题重击，每张议题卡落下时一声 tick。
- **赞助墙**：标题重击，每个等级组一声提示音。
- **terminal**：敲击声、结尾的 glitch 噪声、一个短的上扬。

## 混音与交付
- **混音：** build.sh 先把配乐和音效混在一起（音效 -5 dB），再做 17 kHz 低通，然后两遍 loudnorm（-14 LUFS / -1 dBTP / LRA 11）。
- **交付：** 成片里是混音；分轨另外输出 `_原创配乐.wav` 和 `_音效.wav`（未做响度标准化），方便剪辑师重新混。

## 换和弦或调性
设置 `CHORDS = [(低音 midi, [和弦 midi…]), …]`，每小节一个。例如 Dm–B♭–F–C：
`[(38, [50, 53, 57, 62]), (46, [50, 53, 58, 62]), (41, [53, 57, 60, 65]), (48, [55, 60, 64, 67])]`。

## 换 BPM
- 改 `BPM` 后，所有以拍为单位的东西会一起伸缩；`TOTAL` 要重新算。
- 120–140 都行；低于 110 不燃，高于 150 字来不及读。
