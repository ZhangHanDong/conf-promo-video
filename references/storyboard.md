# 分镜方法：踩拍的「燃版」结构

所有时间都用**拍**表示（128 BPM：1 拍 = 0.469 s，1 小节 = 4 拍 = 1.875 s）。画面（render.py）和配乐（music.py）共用一条拍子时间轴，改 `CUES` / `MUSIC_SECTIONS` 时两边会一起变。

## 标准 92 秒结构（一支真实大会宣传片的用法）

| 拍 | 秒 | 段落 | cue | 配乐模式 |
|---|---|---|---|---|
| 0–8 | 0–3.8 | 终端启动 | `terminal`：敲命令 → 三行输出 → 第 7 拍锁定 | `pad` |
| 8–12 | 3.8–5.6 | 定位 | 两个 `slam`：「一年一度」「XX 开发者的盛会」 | `pulse` |
| 12–16 | 5.6–7.5 | 闪回预告 | 4 张 `flash` 照片，每拍一张 | `pulse` |
| 16–32 | 7.5–15 | 往届蓄力 | 章节 slam「2025 · 城市」+ 2 拍镜头 + 一句 slam + 1 拍快切 | `build` |
| 32–64 | 15–30 | 高潮一：演讲与技术 | 每 8 拍一个 slam，中间 2 拍镜头，后半变 1 拍 | `full` |
| 64–96 | 30–45 | 高潮二：交流与社区 | 同上，结尾 6 个 1 拍快切 | `full` |
| 96–104 | 45–49 | 情绪段 | `pano`：全景横移 + 一句情绪句 | `break` |
| 104–112 | 49–52.5 | 合影 | 4 张 2 拍合影，最后一张 `push` | `full` |
| 112–120 | 52.5–56 | 感谢往届赞助 | `wall`（ghost 样式） | `full` |
| 120–128 | 56–60 | 倒数 | 4 个 slam：「下一站」「城市」「日期」「大会名」 | `count` |
| 128–136 | 60–64 | 揭晓 | `reveal`：KV 信息页逐行出现，URL 被锁定 | `reveal` |
| 136–138 | 64–65 | 章节 | slam「2026 讲师阵容」 | `hit` |
| 138–152 | 65–71 | 主讲 | 7 张 `keynote` 卡，每张 2 拍 | `mid` |
| 152–170 | 71–80 | 分会场 | 3 面 `trackwall`，每面 6 拍 | `full` |
| 170–182 | 80–85 | 今年赞助 | `wall`（accent 样式） | `full` |
| 182– | 85–92 | 片尾 | `endcard`：信息页定格（QA 检查 ≥3 s 静止） | `end` |

**先回顾，再展望**：倒数之前全是往届，倒数之后全是今年。往届画面左上角一直挂 `RECAP` 角标。

## 写字（slam 文案）
- **短**：2–7 个字最好，一屏一句，字号 190–340。英文或长句压到 150–170。
- **成对推进**：「从技术探索 → 到工程实践」「让问题被看见 → 让经验被分享」「从一次交流 → 到下一次共创」。前一句起，后一句落在下一小节的头上。
- **slam 的背景**：用下一个镜头的照片（`bg`），模糊后放在字后面，切到照片时观众已经“看过”一眼。
- **只写事实**：口号可以有态度，但人数、嘉宾、规模不能编（见 truth-and-provenance.md）。

## 选片
1. `contact_sheet.py event.py` 生成带编号的联系表，用 Read 看图。
2. 每段按主题挑：会场与开场 / 讲台与代码投影 / 观众与问答 / 展区与交流 / 细节（周边、吉祥物）/ 合影。
3. 一张照片在全片最多出现两次（一次作 slam 背景，一次正片）。
4. 竖图会自动居中，两侧填模糊背景，但尽量少用。
5. 裁 16:9 时人头被切：给这张图设 `ANCHOR`（0.15–0.6）。底部有水印要保住时，用默认 0.8 只裁上方。
6. 跟踪框 `POIS` 只框**物体**：屏幕上的代码、横幅、吉祥物、设备，不框人脸。读坐标用 `contact_sheet.py event.py --grid B02`。

## 改时长
- **60 秒版**：去掉高潮二（64–96）和分会场墙，后面的拍子整体前移 32；`TOTAL` 和 `MUSIC_SECTIONS` 一起改。
- **30 秒版**：terminal → 2 个 slam → 16 拍高潮 → 倒数 → reveal → endcard。
- **没有讲师数据**：去掉 keynote 和 trackwall 段，把 `mid` 段也删掉。
- 每次改完先跑 `core.py --check`。它会报告 MUSIC_SECTIONS 的空档和超出 TOTAL 的 cue。

## 检查帧
`render.py event.py --stills` 给每个 cue 渲染两帧，并拼成 `WORK/stills_sheet_*.jpg`。逐张看：
- 字有没有溢出、被裁掉；
- 人头有没有被切；
- 跟踪框是不是还框在物体上；
- 赞助墙每排是否放得下；
- 讲师卡的标题是否被截断成「…」。

想看单帧用 `--at 63.2 71.5`。

## 其他镜头类型
回顾向的「燃版」之外，还有一类「工具 / 产品向」的暖场片：素材主要是截图、KV 分层和 8bit 图形，而不是现场照片（约 60 秒，120 BPM，可以循环播放）。

| cue | 用途 | 关键参数 |
|---|---|---|
| `layers` | 万能合成：KV 分层组装、像素徽章、带窗口框的截图、逐条出现的议程、工具名标签 | `bg=dict(img, push, blur, dim, shade)`；`layers=[dict(img, cx, cy, w, at, dur, dx, dy, scale, alpha, rot, spin, drift, pixel, frame)]`；`texts=[dict(text, font, x, y, at, pill, outline, cursor, lock)]` |
| `carousel` | 主题选择器式的 3D 叠卡：斜切卡片横向滑动，焦点卡片放大成完整画面，整屏随主题换色 | `items=[dict(img, name, credit)]`、`focus=[…]`、`header`、`note` |

所有 cue 都可以加：
- `xfade=拍数`：从上一个镜头交叉溶解进来。也可以放在片尾最后一个 cue 上，溶解回片头第一帧，做成无缝循环。
- `cut='flash'|'soft'|'none'`：切点闪白的强度。会场循环片建议用 soft 或 none。

全局开关：
- `HUD=False`：去掉小节计数和时间码；
- `MUSIC_BRIGHTNESS`：配乐亮度，小于 1 时更柔和；
- `ENDCARD_IMAGES`：片尾信息页上的徽章或场地 logo；
- `SILENT_NAME`：额外输出一份无音轨版本；
- `SUBTITLES`：输出 SRT。

**截图类素材的规则：**
- 只用真实截图，并标注「动画为剪辑示意，不是录屏」。
- 不放大到超过原图 1.3 倍左右：1200 px 宽的截图，画面里最多约 1440 px。
- 主题或壁纸的许可要单独核实，仓库的 MIT 许可不等于截图可以随意使用。

## 实拍路线 / 导览片
素材是现场走一遍拍的手机视频，加几张现场照片（竖版 1080×1920，约 77 秒）。

| 功能 | 用法 |
|---|---|
| `clip` | `video=路径, src=(t0, t1), n=拍数`：把源视频的 t0–t1 秒线性压缩或拉伸到 n 拍，实现变速；t0 == t1 时是定格。会自动铺满画面、锐化、调色，可选 `push` 慢推 |
| `markers` | 定位标注：脉冲圆环 + 引线 + 标签，可带编号徽章（例如集章卡章位），用 `x1/y1` 跟随镜头漂移。`layers` 和 `clip` 都可以用 |
| `arrows` | 流动的箭头（`angle=-90` 表示朝画面上方，也就是“往前走”） |
| `ROUTE` | 全局导览界面：顶部 STEP xx/yy 和步骤标题，底部路线进度条加移动的小圆点。`dict(steps=[(拍, 标题, 短名)], end=拍)` |
| `HOLD_BEAT` | 片尾静止画面从哪一拍开始（不用 endcard 时） |
| `MUSIC_STYLE='house'` | chill house 配乐（engine/music_house.py），和燃版 EDM 是两种风格。每个路线步骤自带转场音和提示音，标注弹出时有点击声 |

**注意：**
- 照片上的手绘标记先去掉（按颜色区域做掩膜，再用 OpenCV 的 inpaint 修补），再由视频重新画出干净的标注。不要直接用画了手写标记的原图。
- 竖版要给平台界面留出位置：主要信息放在 150–1500 px 之间。
- 母版文件很大，另外导出一份约 3.5 Mbps 的分享版，方便在微信里转发。
